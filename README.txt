SOLARFLOW PWA v2 — PREMIUM MOBILE UI

Обновление уже существующей установки:
1. Откройте GitHub → spinup-play/solarflow-app.
2. Add file → Upload files.
3. Загрузите ВСЕ файлы из этой папки поверх существующих:
   index.html
   manifest.webmanifest
   service-worker.js
   папку icons
4. Commit changes.
5. Подождите завершения GitHub Pages deployment.
6. На iPhone полностью закройте SolarFlow и откройте снова.
7. Если дизайн не обновился из-за старого кэша — удалите иконку SolarFlow с экрана Домой и добавьте сайт заново через Safari → Поделиться → На экран Домой.

Supabase и код Telegram-бота для этого обновления менять не нужно.
