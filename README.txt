SOLARFLOW OWNER v3

1. Supabase -> Edge Functions -> telegram-bot.
2. Полностью замените код файлом telegram-bot-OWNER-APP-v4.ts и нажмите Deploy.
3. Секрет SOLARFLOW_APP_PIN уже должен быть добавлен в Edge Functions Secrets.
4. GitHub -> solarflow-app -> Add file -> Upload files.
5. Загрузите index.html, manifest.webmanifest, service-worker.js и папку icons поверх текущих файлов.
6. Commit changes.
7. На iPhone закройте SolarFlow и откройте снова. Если старая версия кэшируется, удалите иконку и добавьте сайт на экран Домой заново.
8. При первом запуске введите PIN. Устройство запомнит вход на 30 дней. В разделе «Ещё» есть «Выйти из CRM».

Telegram Mini App для доступа к CRM больше не требуется.
Telegram-бот продолжает принимать клиентские заявки.
