SolarFlow v13 CRM — установка

1) Supabase → SQL Editor → выполнить solarflow-v13.sql один раз.
2) Supabase → Edge Functions → telegram-bot → заменить весь код на telegram-bot-OWNER-APP-v13-CRM.ts → Deploy.
3) GitHub Pages → заменить index.html и service-worker.js → Commit changes.
4) Полностью закрыть SolarFlow на iPhone и открыть снова.

Что добавлено в приложение:
- фотографии объекта внутри заявки;
- полный статусный путь;
- назначение замера/монтажа и календарь;
- чат с клиентом;
- база клиентов;
- внутренние заметки и история;
- смета с позициями и итогом;
- коммерческое предложение с печатью/Save as PDF;
- оборудование: нужно купить / закуплено / установлено;
- стоимость объекта, оплаты, расходы, прибыль;
- ответственный администратор;
- объекты, поиск, фильтры и архив;
- автообновление свежих заявок.

Важно: уведомления при полностью закрытом PWA не являются настоящим Web Push. Текущие уведомления/напоминания работают, пока приложение активно. Для фонового push нужна отдельная Web Push/VAPID настройка.
